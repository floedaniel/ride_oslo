# Ride Oslo Shiny app – implementation plan

Spec: `docs/superpowers/specs/2026-10-18-shiny-app-design.md`. Execution: native (user said "do it").

## Global constraints
- R 4.5, packages already installed: shiny 1.14, bslib 0.12, leaflet 2.2.3, plotly 4.12, DT 0.34,
  sf 1.1, igraph 2.3, nbpMatching, FITfileR 0.1.11, elevatr, terra, testthat 3.3. No new installs.
- Planner logic (cluster growth, Rural Postman solve, Euler walk, refine) is moved, not changed.
- `done_rides/` is the only ride history. `next_ride/` only ever holds `next_ride.gpx`.
- CRS: EPSG:25832 for all metric work, 4326 for maps/GPX.

## Review focus (failure modes no task test covers directly)
1. A corrupt/empty/no-GPS `.fit` in `done_rides/` → skipped with a notification, app keeps running.
2. A ride outside Oslo (holiday) → read fine, counts 0 km new street, does not break stats.
3. Uploading a file that already exists in `done_rides/` → not duplicated (same name overwrites).
4. Only 1 ride → per-week pace and finish date show "n/a", nothing errors (test in stats).
5. Everything near home ridden (empty pool) → planner widens reach instead of stopping.

## Tasks
1. **Extract** – `R/osm_extract.R`: `extract_oslo(norway_pbf, out_dir)` writes
   `data/oslo_boundary.gpkg`, `data/oslo_districts.gpkg` (16 bydeler + Marka),
   `data/oslo_ways.gpkg` (highway lines intersecting Oslo + 1 km). Run once, check counts.
2. **Network** – `R/config.R` (`default_config()`), `R/network.R`: `way_filter(ways)` (pure,
   new rules), `way_class(highway)` → road/path/gravel, `build_network(cfg)`,
   `load_network(cfg, rebuild)` with per-edge `in_goal`, `district`, `cls`, sample points and
   WGS84 simplified geometry. Tests: `tests/testthat/test-network.R` (sidewalk out, gravel track
   in, ground path out, bicycle=designated path in, private out).
3. **Rides** – `R/rides.R`: `read_points(f)`, `read_track(f, gap_m)`, `ascent_m(e)`,
   `ride_summary(d, gap_m)`, `load_rides(cfg, net)` with per-file cache → rides table, per-edge
   `cover` and `first_ride`. Tests: real `.fit` reads, ascent on a known vector, bad file → NULL.
4. **Stats** – `R/stats.R`: `progress_totals()`, `district_progress()`, `class_progress()`,
   `weekly_rides()`, `predict_finish()`, `projection_series()`. Tests: hand-made rides tables
   incl. the 1-ride case.
5. **Planner + export** – `R/planner.R`: `plan_route(net, prog, settings, progress = NULL)`
   (closure around the moved solver; modes roads / roads+paths / all; widen reach if pool
   empty); `R/export.R`: `write_gpx_track()`, `route_elevation()`, `save_next_ride()`.
   `plan_next_ride.R` becomes the thin wrapper. Check: script runs end to end.
6. **App** – `app.R`: navbar with Ridden / Next ride / Statistics; reactivePoll on `done_rides/`;
   upload; plan with progress; last plan persisted in `data/cache/last_plan.rds`. Check: launch,
   hit each page, plan once, download GPX.
7. **Docs** – README update.
